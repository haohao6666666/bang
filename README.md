## 产品介绍

知途是一款面向孩子与青少年的AI成长陪伴应用，旨在解决“做了很多，却忘了做到哪里；留下作品，却难以看见成长过程”的问题。不同于只记录任务或时长的工具，知途将任务、专注、交流、作品与足迹串联，让下一次探索不必从头开始。

用户从安排一件小事开始，自定义专注时长，结束后自主选择完成、继续或放下。系统分别记录投入与完成状态，不把“花过时间”等同于“已经完成”。经用户开启聊天整理，AI伙伴“小芽”围绕具体经历交流，记住上次进度与下次继续点；用户也能纠正或删除记忆。开启作品阅读后，小芽可结合文档或照片回应，让陪伴建立在真实内容之上。

足迹通过日历与印章册呈现真实行动，将草稿、照片、文档与当天经历归到同一件事。每枚印章都有来源和获得条件，系统也可根据具体作品或经历生成独特纪念章，让成长有迹可循。任务、计时和作品保存不依赖模型在线，记录以本机保存为主，支持导出。

知途不以分数或排行榜定义成长，而是尊重每个人的节奏。回应赛题“你希望教育如何对待下一个像你一样的人”，我们希望：不只看见结果，也看见走过的路，让每一次探索，都被好好记住。

## 一条能继续走下去的路

**安排一件事 → 专注 → 可选地聊两句或留下作品 → 自动进入足迹 → 下次接着做。**

| 页面 | 可以做什么 |
| --- | --- |
| 今日 | 安排任务，自定义专注时间，暂停、继续、结束；到点提醒后选择完成、继续或放下。点击右上角小芽即可聊天。 |
| 足迹 | 左右滑动查看单日日历，点击整张卡片进入当天详情；回看作品、任务时间分布和分类印章册。 |
| 我的 | 调整陪伴与作品阅读设置，重新体验互动教程，管理记忆、导出记录。 |

### 小芽，记得你走到哪里的小伙伴

- 开启聊天整理后，围绕当前任务接着聊，记住具体进度和下次继续点。
- 开启作品阅读后，可结合照片或 TXT、DOCX、文本型 PDF 的内容回应。
- 聊天、作品和专注记录关联到任务与日期。作品页只展示作品。
- 可以在聊天里纠正或让小芽忘掉一件事，也可以在设置里关闭或清除记忆。

### 足迹，看见真实发生的事情

- 日历里的 ✓、○、× 对应用户选择的完成、继续和放下，计时不会自动把任务标成完成。
- 正在专注的任务也会进入当天足迹；时间图表按类别统计实际专注时间。
- 日历只盖首次获得的不同印章图案，重复获得的次数收在印章册。
- 具体作品或经历可以留下独特纪念章，并能回到对应记录。

## 快速运行

需要 Node.js 24 和 npm。在仓库根目录运行：

```bash
npm ci
npm run dev
```

打开 **http://127.0.0.1:4173/**。任务、计时与作品保存可以独立使用；本地聊天、读图和绘图需要在服务端配置自己的 API Key。完整步骤见 [运行说明](docs/RUNNING.md)。公开体验链接已配置服务端模型。

## 源码与材料

```text
src/                 前端页面、计时、足迹、作品、小芽与互动教程
server/              聊天、记忆、作品阅读、绘图及生产服务
shared/              前后端共用的数据与规则
public/assets/       页面使用的插图、印章与设备资源
artwork/             插画原始文件及设计参考
db/ + drizzle/       数据结构与迁移
tests/               交互、数据、模型接口和部署测试
scripts/             本地预览、构建与运行时检查
deploy/tencent/      腾讯云 Docker Compose 与 HTTPS 配置
docs/                产品、运行、演示和技术文档
docs/showcase/       项目图、比赛海报和产品说明书
```

前端使用 React、TypeScript、Vite；服务端使用 Node.js。当前公开体验部署在腾讯云，通过 Caddy 提供 HTTPS。文本、视觉和绘图通过独立服务端适配器接入，密钥不进入浏览器。

## 数据与使用

任务、专注记录及作品原件主要保存在当前设备浏览器；已授权的聊天整理和作品阅读会把必要内容交给服务端模型处理。服务器按浏览器令牌隔离后台记忆。不同设备或不同网址的记录不会自动同步，请及时导出重要记录。

仓库不包含 API Key、服务器登录凭据、私人聊天、作品原件或后台记忆。历史存储标识保留 `jixiang` 前缀，以兼容已有数据；产品名称统一为知途。
