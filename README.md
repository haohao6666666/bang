# 迹向

迹向是一款本地优先的成长记录产品：安排一件事，专注一小段，按需要和小狗聊两句或留下作品，记录会自动回到对应任务与日期，下一次打开可以接着做。

## 当前方向

本轮在原项目上重构，保留 v5 本机数据、FocusLog、印迹册和迁移逻辑。底部导航收敛为「今日 / 足迹 / 我的」，手机默认使用真实页面视口，不再显示模拟器外框、假状态栏或模拟键盘。

- 今日路线支持自定义专注时长、暂停、继续和结束。暂停不弹表单，结束不会强制总结，也不会自动把任务标成完成。
- 小狗结合当前任务安静陪伴。结束后可以聊两句，也可以直接离开；用户原话、任务进度、作品和日期会在后台整理。
- 作品支持照片、文档和一句话记录，可预览、编辑和删除，自动关联当前任务。内容识别暂未开启，不会把未识别内容写成结论。
- 足迹保留原有时间印迹和日历布局。具体作品或经历出现后，纪念印章在后台自动生成并去重，日历主要展示日期和图案，点击查看来源。
- 首次使用会说明后台记忆。设置中可以关闭或清除；聊天里说“记错了”或“忘掉这件事”会触发对应记忆清理。后台文档不通过前端静态资源提供。
- 收藏目前支持真实的 JSON 导入和逐条授权；账号收藏自动同步尚未接通。

所有面向用户的 AI 文案保持简短、口语化并以具体记录为依据。模型不可用时，任务、计时、保存和浏览仍可使用；后台生成失败会静默重试。

## 本地运行

```bash
npm install
npm run dev
```

构建与验证：

```bash
npm run check:runtime
npm run test:ai
npm run test:sites
npm run test:runtime
npm run build
```

## 目录

- `src/Prototype.tsx`：产品页面、任务流程和本机数据状态。
- `src/WorkCapture.tsx`：作品与一句话记录。
- `src/TaskCompanion.tsx`：小狗任务收尾对话。
- `src/aiContracts.ts`、`src/aiSnapshot.ts`：服务端调用边界与最小化记录快照。
- `server/service.mjs`、`server/index.mjs`：密钥、后台记忆、文本陪伴和自动印章服务。
- `src/stampBook.ts`、`src/stampDefinitions.ts`：印迹册聚合、印章定义与版本迁移。
- `src/mobile/MobileRuntime.tsx`：真实移动视口与测试夹具运行时。
- `public/assets/`：迹向插图和运行时素材。
- `docs/`：接入说明、流程资料和验收记录。

印迹册只从真实 FocusLog、成果、便签和作品判断记录，不把任务名称或时长当成学习效果。旧版数据会继续按迁移逻辑读取。
