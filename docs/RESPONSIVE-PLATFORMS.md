# 知途 · 真实浏览器多端适配

2026-10-04。在现有产品上修正安卓、鸿蒙微信内置浏览器和电脑网页布局，保留 iPhone 的主要视觉与操作方式。本轮不上传 GitHub。

## 具体变化

- 今天的事：三个点改为固定尺寸 SVG，消除系统字体、文字缩放和默认按钮内边距引起的溢出；手机点击区域 40px，电脑 44px。菜单可通过点外部或 Escape 收起。
- 长任务名、英文连续字符串和作品文件名按容器换行。类别、时长、日期保持可读。
- 电脑今日页：任务列表与操作侧栏分别排版，列表高度不会撑开右侧卡片。作品区按窗口宽度排列两列或三列，短文档卡片不随图片卡片拉高。
- 日期详情和统计图：标题、任务文字、时长和圆环在窄屏内布局。印章解释仍来源于原有元数据，获得规则保持原样。
- 弹层：米白纸张、柔和阴影、清晰关闭按钮。修正嵌套弹层导致已关闭的设置残留问题。聊天通过显式 class 控制布局，不依赖微信旧内核可能缺少的 CSS :has 支持。
- 手机键盘：使用可见视口和布局视口的尺寸适配，背景页面保持原位。横竖屏切换重新建立页面尺寸，避免误判为弹出键盘。桌面窗口调整大小不会被当成手机键盘。
- 框架：继续使用真实浏览器，没有 Android / Pixel 模拟器、假状态栏或假键盘；保留放大页面的能力。

## 验证方法与范围

新增跨平台浏览器回归：华为微信 320px / 393px、安卓 Chrome 412px、iPhone 390px、电脑 1000px / 1440px。覆盖长任务、图形按钮边界、菜单、专注切换、文件预览、日历详情、图表、印章册、设置关闭，以及安卓键盘收放与旋转。

附加布局巡检使用 320、360、393、412、600、768、1000、1280、1440px 的宽度。浏览器自动化使用 Chromium / Edge 与 WebKit，华为微信使用其用户代理及触摸视口模拟；这不能代替华为真机和微信具体内核的最终手感检查。

runtime 完整性、TypeScript、生产构建通过；Chromium / Edge 浏览器回归 81 项、WebKit 19 项、Sites 4 项、生产服务 1 项、模型与记忆服务 30 项通过。公开站点更新后另核对实际构建与页面交互。
