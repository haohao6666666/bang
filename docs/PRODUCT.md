# 知途 · 产品介绍

知途是一款面向所有希望成长和回顾自己的人的AI成长陪伴应用，旨在解决“做了很多，却忘了做到哪里；留下作品，却难以看见成长过程”的问题。不同于只记录任务或时长的工具，知途将任务、专注、交流、作品与足迹串联，让下一次探索不必从头开始。

用户从安排一件小事开始，自定义专注时长，结束后自主选择完成、继续或放下。系统分别记录投入与完成状态，不把“花过时间”等同于“已经完成”。经用户开启聊天整理，AI伙伴“小芽”围绕具体经历交流，记住上次进度与下次继续点；用户也能纠正或删除记忆。开启作品阅读后，小芽可结合文档或照片回应，让陪伴建立在真实内容之上。

足迹通过日历与印章册呈现真实行动，将草稿、照片、文档与当天经历归到同一件事。每枚印章都有来源和获得条件，系统也可根据具体作品或经历生成独特纪念章，让成长有迹可循。任务、计时和作品保存不依赖模型在线，记录以本机保存为主，支持导出。

知途不以分数或排行榜定义成长，而是尊重每个人的节奏。回应赛题“你希望教育如何对待下一个像你一样的人”，我们希望：不只看见结果，也看见走过的路，让每一次探索，都被好好记住。
