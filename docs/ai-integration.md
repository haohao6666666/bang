## 现在可以做什么

1. **我的 → 模型与收藏**：配置文本和绘图服务，导入知乎 / 小红书收藏。
2. **回响 → 和今天聊一聊**：选择是否包含日记、是否参考授权收藏，展开实际发送内容，然后明确同意本次调用。
3. **每日回声**：C1 先理解本地记录。需要经验或安静日重看收藏时，将相关授权摘录交给 C2；展示可借鉴部分、适用条件、局限、原文与本地依据。
4. **确认与选择**：修改、确认或隐藏草稿。确认回声不会自动安排任务；每条小尝试需再单独选择，进入下一天的「明日小尝试」。到了日期后，可加入今日路线。
5. **周回声**：查看选定日期向前七天的范围，至少有三个授权日记日期，每条保留的观察必须由至少两个日期的具体证据支持。可以修改、确认、隐藏和按日期回看。
6. **足迹 → 我的印章册 / 日期详情**：以当天真实投入、成果或便签启发一枚 AI 纪念印章。绘制说明可修改；生成结果存入本机，独立于原有时间章与成长章，不改计数。

## 配置 API

当前没有填入真实密钥，实际鉴权、账号额度与模型可用性需要在填入 Key 后验证。界面的「已填写密钥」只表示配置存在，不代表已通过调用测试。可以直接在应用的密码字段填写，不需要把密钥写进聊天、源码或前端环境变量。

默认文本模型是通义千问 `qwen-plus`，绘图是通义万相 `wan2.2-t2i-flash`。也支持 DeepSeek 文本接口、火山方舟豆包文本与 Seedream 绘图接口。豆包文本使用你控制台的模型 ID 或 `ep-…` 接入点；模型名称可编辑。只允许匹配厂商的大陆官方 HTTPS 域名。

也可复制 `.env.example` 为 `.env`，在本机填写；环境文件只由 Node 读取。通过界面保存的 `.local/model-config.json` 优先于环境变量。换厂商或地址时不会沿用旧密钥，空密钥需要重新填写；同厂商、同地址留空则保留原值。

`npm run dev` 同时启动界面 4173 与本机 API 4175，监听 `127.0.0.1`。测试端口 4174 对应 API 4176。需要 Node.js 22 或更高版本。本版本是单人本机服务；静态 `dist/client` 或 Sites Worker 本身不包含 Node 模型服务，不能只发布静态目录就声称云端 AI 已接通。

## 收藏来源边界

当前支持**导入收藏**，不包含已验证的个人账号 OAuth 收藏同步，也没有启用联网搜索。公开可核实的小红书开放平台主要面向电商，未找到可直接用于本项目的个人收藏授权接口。知乎也尚未确认可用的第三方个人收藏同步接口。因此不会显示虚假的「账号已连接」，不会索要账号密码、Cookie 或绕过访问限制。

支持粘贴分享消息中的 HTTPS 链接，补充标题和自己有权使用的原文摘录；仅保存链接的内容不参与分析，不会假装读取了原网页。JSON 导入格式如下，最多 200 条、2 MB，按链接去重；每条导入默认未授权，编辑原文后也重新取消授权。

```json
[
  {
    "title": "一条想重新理解的阅读方法",
    "url": "https://www.zhihu.com/question/实际问题ID/answer/实际回答ID",
    "excerpt": "粘贴你有权使用的原文片段，至少二十字。不要把作者没有说过的话写成原文。"
  }
]
```

回声只接受与当前日期匹配的本地证据 ID。外部引文必须逐字包含在本次授权摘录内，来源 URL 取自导入记录。不存在、未授权或无法核对的来源会被拒绝。每次最多处理 80 条授权收藏，C2 使用其中按本地线索排序的最多 6 条；模型负责判断相关性，引用校验并不能保证观点正确，最终仍由用户判断。

如果 C2 不可用或结果不合格，保留 C1 本地草稿并标明状态，不补造来源。没有收藏、没有合适内容或未开启参考收藏时，依然可生成本地回声。

## 存储与费用

- 浏览器仍保存原 v5 学习记录；收藏与纪念章索引使用新增的 `jixiang-ai-workspace-v1`，默认日记/收藏不参与分析。密钥只放在本机服务文件或 `.env`，不进 localStorage、不回传前端、不写入导出。
- `.local/model-config.json` 是本机明文配置，应由设备账户保护；不是系统钥匙串。`.local/` 与 `.env` 已被 Git 和交付压缩包排除，开发服务也禁止静态读取它们。不要分享这个目录。
- 生成的图片和来源信息保存在 `.local/stamps/`，页面使用本机图片地址。导出记录的 JSON 包含索引与说明，不内嵌图片；完整迁移需额外复制这个图片目录。浏览器里的「清除记录」会明确保留服务端配置和图片文件，避免误删。
- 图像服务实际接收固定绘图风格提示加用户确认的绘制说明，不发送日记全文、收藏、成果正文或原始任务标题。来源编号等仅供本机服务核对，不交给绘图厂商。
- 同一天成功生成后重复请求返回同一枚，不重复计费。万相任务号在提交成功后立即落盘，断网后继续查询同一任务；更换厂商、模型或地址时先恢复原配置查询。若提交尚未拿到任务号就断网，或豆包同步调用中断，无法保证供应商没有计费；不会自动重试提交。
- 「停止等待」不会保证取消供应商端已经运行的任务。已失败或过期的万相任务保留任务文件以避免重复收费，需要检查控制台后再处理，不会悄悄重复发起绘图。
- 本机接口校验 Host、Origin、自定义请求头和大小，供应商返回地址经过限定再下载。错误信息不直接回显供应商原始响应或密钥。
