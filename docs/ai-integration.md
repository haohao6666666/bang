# 迹向 · AI 陪伴、记忆与自动整理

迹向把 AI 放在后台，用户先完成任务、计时、保存作品或聊天；这些基础操作直接写入本机数据，不等待模型。模型不可用时，任务、FocusLog、作品、日历和印迹册仍可正常使用。

## 用户能看到的流程

1. **今日**：安排一件事，开始、暂停、继续或结束专注。结束不会强制总结，也不会自动把任务改成完成。
2. **留下内容**：在任务下添加照片、文档或一句话记录；任务收尾时可以和小狗聊两句，也可以跳过。
3. **自动整理**：聊天结束、成果保存或作品上传后，后台按用户、任务和日期整理原话、继续点和来源。连续操作按事件去重，失败静默重试。
4. **足迹**：日历保留真实时间印迹。出现具体作品或经历后，后台最多为当天收好一枚纪念印章，并把来源指回当时的记录。
5. **我的**：首次使用会说明自动整理。设置中可以关闭后台记忆、清除已整理记忆；用户说“记错了”或“忘掉这件事”时，服务端会删除或更新对应内容。

页面不显示模型名称、提示词、推理过程或“生成回顾 / 生成印章”按钮。整理内容可以修改、收起或删除；隐藏和删除会同步后台记录。后台记忆文档只存在服务端数据目录，不由前端静态资源暴露。

## 服务端配置

密钥只由本机 Node 服务读取，优先使用 `.local/model-config.json`，其次读取 `.env`。示例变量见 `.env.example`。可以配置兼容 OpenAI 的文本服务和绘图服务；前端不保存或导出密钥，交付包也排除 `.env`、`.local` 和模型配置。

`npm run dev` 会同时启动界面和本机 API。开发 API 只接受本机或同一局域网请求，并检查 Host、Origin、自定义请求头和请求大小。静态构建只包含界面，不会把服务端密钥或记忆文档打进 `dist/client`。

## 发送边界

- 文本陪伴只接收当前任务、用户消息和必要的结构化记忆；后台回看只使用当天的具体作品、成果、便签或用户原话。
- 纪念印章只接收当天的作品或经历证据，不根据任务名、计划时长或累计时间推断学习效果。
- 收藏只支持真实可用的 JSON 导入和逐条授权。账号收藏自动同步和联网搜索尚未接通，未授权内容不会发送。
- 内容识别暂未默认开启；照片和文档先保存、预览、编辑和删除，不把未识别内容写成结论。

## 记忆与后台任务

结构化记忆文档使用 `version`、`taskId`、`dateKey`、`quotes`、`nextSteps`、`sources`、`inferences` 和去重事件记录。用户原话标记为 `source: "user"`，模型整理不会写入长期性格标签，`inferences` 默认为空。

后台任务写入 `.local/background.json`，按事件指纹合并；文本和绘图各有调用次数与日费用上限，可用环境变量调整。服务端会在三次失败后暂停该事件，原始记录仍保留。清除后台记忆会清理记忆与后台回看，保留本机任务和 FocusLog。
