# 知途 · 导游式路演

建议约4—5分钟，边操作边讲。让一位评委操作，其他评委看同一块展示屏；先指出按钮，再说下一句，等页面出现后再往下走。

整条路线：扫码 → 安排与专注 → 小芽记忆 → 作品变化 → 当天回顾 → 时间与印章 → 我的 → 收尾。

## 上台前

展示设备提前进入三天演示，加载草稿、上色版、实验截图与文档，再退出演示回到今日。保持同一个网址与浏览器，不清理个人记录。

公开链接：https://zhitu.124-156-163-245.sslip.io/

若首次教程出现，先点提示气泡右上角的×结束引导，由你带评委走这一条路线。“我的”中可以重看教程。演示期间不用再同时跑完整教程。

## 第一站：扫码，认识知途（约25秒）

**让评委做：** 扫码打开网页，停在今日。

**你说：**

> 一张草稿，值得留下的，还有它后来变成什么的过程。
>
> 各位评委好，知途是一款面向所有希望成长和回顾自己的人的AI应用。它把任务、专注、交流、作品和回顾连在一起。接下来请跟着我点一遍，看看一段经历怎样被收好。

**指向：** 底部“今日、足迹、我的”。

> 功能丰富，但入口只有三个。我们从今日开始。

## 第二站：安排一件事，按自己的节奏做（约45秒）

**让评委做：** 点击“添加一个想做的事” → 输入“画一片叶子” → 选择绘画类别 → 自定义1分钟 → 点击“加入路线”。选中刚添加的任务，点击“开始投入”，再点“先停一下”，最后点“结束”回到今日。

**你说：**

> 先安排一件小事，比如画一片叶子。这里有常用时长，也可以自定义。
>
> 请点开始。小芽会安静看书；点暂停，它也陪着休息。暂停后可以换一件事，回来继续原来的计时。
>
> 我们先结束这一段。到点会有声音提醒，完成、下次继续、先放下或延长，由用户自己决定。做过的一小步，也会留下来。

**注意：** 本步骤展示开始、暂停和结束，不等待一分钟闹钟，也不把“结束计时”说成“任务已完成”。刚才的短体验不要求立即获得时间印迹。

## 第三站：让小芽接住上一次（约40秒）

**让评委做：** 点击“进入评委演示” → 今日顶部选择10/3 → 点击右上角小芽 → 输入“小狗那幅画上次做到哪了？” → 看回复 → 关闭聊天。

**你说：**

> 刚才体验了怎样开始。现在切到预置的三天情景，看持续使用后的样子；它和个人记录分开。
>
> 请选第二天，问小芽“小狗那幅画上次做到哪了？”
>
> 陪伴的温度来自记得具体经历：那张草稿、说过的话，还有下一次想继续的地方。用户愿意分享，它就在后台整理，也能被纠正或要求忘掉。

**注意：** 三天演示中的对话是预置情景，不能说成现场真实模型调用。评委想试真实聊天时，退出演示后开启小芽聊天即可。

## 第四站：把前后变化放在一起（约45秒）

**让评委做：** 回到今日，演示日期选10/4 → 底部“足迹” → “作品” → 展开小狗照片前后对比；随后打开一份实验截图或文字文档。

**你说：**

> 请把草稿和上色版放在一起。第一天留下的想法，第三天有了新的样子，变化就能直接看见。
>
> 再看实验截图和文档。知途能收好学习、创作和项目实践，成长可以有很多种样子。开启作品阅读后，小芽能结合照片或文档回应，作品还可以编辑、删除和重新打开。

**趁评委看作品，讲技术：**

> 技术上，前端用React和TypeScript，后端用Node.js。浏览器先保存记录，服务端按任务和日期关联记忆，再调度文本、视觉和绘图模型，分别负责交流整理、作品阅读和纪念印章。AI在后台补充内容，基本记录不等模型。

## 第五站：把一天翻成一页（约30秒）

**让评委做：** 点击“日历” → 左右翻到10/4 → 点击整张卡片任意位置 → 查看当天详情 → 点击“返回日历”。

**你说：**

> 请翻到这一天。勾表示做完，圈表示还要继续或尚未完成，叉表示先放下。
>
> 点开整张卡片，任务、时长、作品和简短小结就收在同一页。用户回看时，可以找到当时做了什么，也找到还想继续的问题。

## 第六站：看时间，也看经历的来历（约35秒）

**让评委做：** 在日历页看“时间花在哪儿”，切换统计范围或点一个类别 → 点击“我的印章册” → 切换类别 → 打开一枚已获得的章。

**你说：**

> 圆环按类别显示实际专注时间，能看今天、近七天、本月和全部，帮助回看自己的时间去了哪里。
>
> 印章分为时间印迹、坚持、探索、突破和成长五类，都有条件和来源；具体作品还能留下独特纪念章。日历卡片最多展示六种，详情保留全部数量。
>
> 时间和普通印章由记录与规则计算，AI负责整理与表达。这些纪念能够翻回当时的经历。

## 第七站：记录掌握在自己手里（约25秒）

**让评委做：** 点击“我的”，查看陪伴开关、导出和重看教程的入口。只看入口，不强制修改开关或下载文件。

**你说：**

> 这里可以分别管理记忆、主动陪伴和作品阅读，也能关闭或清除记忆。作品和聊天可以导出成直接阅读的小册子，收藏链接和原文片段也能授权作为交流参考。
>
> 一个公开链接适配iPhone、安卓、鸿蒙和电脑。第一次使用有互动教程，模型暂时不可用时，任务、计时和作品保存仍可使用。

## 最后一站：回到成长与Echo（约20秒）

**操作：** 留在产品页面，不再切新页面。

**你说：**

> 成长发生在人生的每个阶段，也包括试错、调整和重新开始。
>
> 回应Echo，知途希望今天留下的经历，在未来回看时再次产生意义：看见自己如何走到这里，也找到继续出发的方向。
>
> **知途，让每一次探索，都被好好记住。**
>
> 接下来您可以退出演示，留下自己的任务，试试真实聊天，或者上传一份作品。

## 现场节奏

- 全程使用“请点这里 → 看见什么 → 这有什么价值”的顺序。
- 页面还没出现时先等一下，不抢着讲下一站。三天素材提前加载，减少现场等待。
- 时间紧时，第二站只看任务与时长选项；重点保留小芽记忆、作品对比和当天详情。
- 有人想体验真实AI时，退出演示，按意愿开启聊天与作品阅读；用户材料由其自己选择。
- 不在主流程里等待现场绘图，展示已有纪念章及其来源即可。
- 不请评委同时跑完整新手教程，也不要求逐项打开每个设置；让所有操作服务于同一段成长故事。
