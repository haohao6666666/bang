## 首次访问

旧版公开页面在关闭缓存、2.5 Mbps 下载速度、100 ms 人工延迟条件下，首页小狗约 2.7–2.8 秒显示。发现旧 favicon 为约 585 KB 的大图片。

新版本按显示尺寸提供小图，页面优先预加载欢迎小狗与字标，低优先级预加载两个实际使用的小插图，favicon 降到约 4 KB。最终公开站在关闭缓存、2.5 Mbps 下载速度、100 ms 人工延迟条件下，首页小狗为 1.63–1.79 秒；手机 1 倍、3 倍屏幕密度及桌面宽度的首屏全部插图最迟为 1.93 秒。测试使用新用户上下文；网络速度会影响实际显示时间。结果保存在 .local/polish/final-public-first-visit.json。
