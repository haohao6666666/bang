# 日历印章与玻璃提示

日历卡片依据对应日期的专注记录显示印章，不再把时间印迹限制在首次获得的那一天。相同图案合并，每张卡片最多展示六种；超过三种时分为两行盖在纸张右下方。没有达到获得条件时不画章，也不放空圈。

点击卡片任意位置，包括印章，可以打开该日期的详情。详情不限制种类数量：相同图案只放一张，标明全部名称和当天的数量。坚持、探索、突破与成长章继续出现在各自实际获得的日期。收藏册获得条件、首次获得日期、FocusLog、历史数据和 migration 均保持原有逻辑。

印章悬停说明采用暖白色半透明磨砂玻璃，支持 WebKit 背景模糊；不支持时回退为暖白实色。提示层不接收点击或滑动，以免遮住操作。出现原因只作简短预览，详细内容留在当天记录中。

验证覆盖三天演示的 10/2、10/3、10/4 和个人记录：320、393、412、1366 像素布局下的六种上限、完整详情数量、图案去重、卡片点击、图片加载及上下滚动。Chromium 完整运行时测试 101 项通过，WebKit 日期与滚动检查 14 项通过（跳过一项仅适用于 Chromium 的触摸检查）；追加玻璃提示检查在 Chromium 和 WebKit 均通过。check:runtime、TypeScript、构建、Sites 与生产服务测试通过。
