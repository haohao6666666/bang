# 知途 · 腾讯云部署

部署现有项目的生产构建和 Node 服务。小芽聊天、识图、记忆与自动纪念章由同一服务器处理；浏览器中的历史任务、FocusLog 与作品原件继续保留，不自动公开或迁移。

## 服务器准备

使用已有 Linux 云服务器，安装 Docker Engine 与 Compose 插件。服务器安全组只开放实际使用的 SSH 端口和 80、443；8080 与模型 API 端口不对公网开放。

如果使用域名，需要域名解析到该服务器，并满足所选腾讯云区域对网站接入的要求。未配置域名时，可先用公网 IP 访问；正式 HTTPS 地址在域名可用后配置。不要把未完成的注册或尚未运行的服务器当成已部署。

## 启动

1. 将不含密钥、`.local`、个人聊天和作品的源码部署到 `/opt/zhitu`。代码包不包含 `node_modules`。
2. 在 `deploy/tencent/` 将 `.env.example` 复制为 `.env`，设置访问地址和三个模型的服务端配置。文件权限设为 `600`，不要上传到源码仓库。API Key 通过安全连接单独写入。
3. 在该目录运行 `docker compose up -d --build`。Caddy 在前面提供网页入口，Node 服务只在容器网络内监听。使用域名时，Caddy 自动申请和续签 HTTPS 证书。
4. 查看 `docker compose ps`，确认两项服务运行且应用健康。打开首页，检查聊天、上传、日历详情、教程和记忆接续；再交付公开链接。

当前访问地址由 `.env` 中两项共同决定：

- 域名：`SITE_ADDRESS=你的域名`，`PUBLIC_ORIGIN=https://你的域名`。
- 公网 IP：`SITE_ADDRESS=http://你的公网IP`，`PUBLIC_ORIGIN=http://你的公网IP`。

`PUBLIC_ORIGIN` 仅写协议和主机，不带页面路径；不要设通配符。公网访客不能在界面中修改服务器模型配置。

## 保存与更新

后台记忆与生成图片保存在 `zhitu-data` 持久卷。重建应用镜像不会删除它们；不要运行 `docker compose down -v`。升级前备份此卷及服务端 `.env`，只替换源码，再重建应用。

首次在新的公网地址打开，浏览器记录属于新地址，电脑局域网历史不会自动出现在这里。服务器记忆按每台浏览器的随机令牌隔离，不能当成账号跨设备同步。原手机入口和历史数据可以继续使用。

演示入口：底部「我的 → 重看新手教程」。教程采用真实页面高亮，按气泡指引操作，任务与作品按正常使用保存。
