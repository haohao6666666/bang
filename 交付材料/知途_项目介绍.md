# 知途项目介绍

知途是一款陪伴并记录成长的教育类产品。它把孩子的一件事从“安排”带到“专注”，再把聊天、作品与当天的足迹连起来。下次打开同一件事，可以接着上次的进度往前走。

产品的主流程很简单：安排一件事 → 自定义时长并专注 → 时间到后自己决定完成、继续或放下 → 可选地和小芽聊两句或留下作品 → 在足迹里回看。倒计时不会把“花过时间”误当成“已经完成”。

小芽是一只会记得具体经历的小狗。用户开启聊天整理后，它围绕正在做的事简短交流，记录有用的继续点；用户也能让它纠正或忘记。经用户开启作品阅读后，它可以阅读文档文字或照片。任务、计时与作品保存不依赖模型是否在线。

足迹像一本个人收藏册：单日卡片写下当天的事情和完成状态，日期详情汇集投入、作品与小芽整理的小结；时间分布用不同颜色说明投入方向。印章册按时间印迹、坚持、探索、突破和成长分类，每枚章有来源与获得条件。有具体作品或经历时，还可以自动得到一枚与那天相关的纪念章。

视觉以米白纸张、柔和的活动色、嫩芽和小芽为核心。小芽在专注时读书、暂停时休息、结束时欢呼；印章像手账里留下的轻微印泥痕迹。整体克制、温和，重点让真实做过的事成为画面主角。

用于海报、KT 板和 PPT 时，建议用一个连续场景讲故事：一件任务、一次专注、一句聊天或一张作品、翻开日期页、下次继续。可突出“被记住的进度”和“有来历的印章”，不要把知途表现成自动评价孩子能力或凭空授予成就的系统。
